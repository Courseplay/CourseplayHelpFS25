# CourseplayHelpFS25

Repository for the FS25 Courseplay Website: https://courseplay.github.io/CourseplayHelpFS25

## Functionality

The website content is the same as the in-game help menu.
The `generate_from_xml.py` script automatically fetches the required XML config, translation files, and textures directly from the [Courseplay FS25 repository](https://github.com/Courseplay/Courseplay_FS25) to generate the documentation pages for the website.

Please don't edit translations or documentation text directly in this repo, as all language files are sourced automatically from the main Courseplay FS25 repository.
