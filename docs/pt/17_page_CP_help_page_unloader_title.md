# Descarregador da ceifeira

  
O modo de descarregador do Courseplay funciona com ceifeiras, colhedoras e colhedoras rebocadas conduzidas pelo Courseplay.  
Não funciona com picadoras.  
Podes usar um reboque normal ou um reboque com sem-fim para descarregar uma ceifeira.  
Para esvaziar reboques, podes usar o trabalhador da Giants ou o AutoDrive.  
Iniciar o descarregador requer algumas coisas:  
- Precisas de ter um único reboque ou reboque com sem-fim atrelado. Vários reboques não são suportados.  
- Usa o ícone de alvo no HUD para selecionar o campo a ser colhido. O descarregador descarrega todas as ceifeiras conduzidas pelo Courseplay a trabalhar nesse campo.  
- Tens de estar no campo ou a menos de 20 metros do campo para iniciar o descarregador.  
  
Os descarregadores têm apenas algumas configurações que podes afinar:  
- Podes definir o nível de carga a partir do qual o descarregador se considera cheio. Isto  
serve para evitar esperar que uma ceifeira chame com um reboque quase cheio.  
- Podes usar os ajustes no HUD para corrigir a posição do descarregador debaixo do tubo da ceifeira.  
  


## Usar reboques

  
Se usares um reboque para descarregar, há duas formas de transportar a colheita para um silo ou para um ponto de venda: o trabalhador da Giants  
ou o AutoDrive.  
Podes usar o menu de IA e criar um trabalho, activando depois a função do trabalhador da Giants e o destino de descarga no  
fundo da lista, ou activando o ícone da roda no HUD.  
Neste último caso, tens de escolher a estação de descarga depois de o ícone da roda ficar azul.  
  
Esvaziar um reboque com o AutoDrive funciona da mesma forma que usar um reboque de carga; vê os tutoriais do AutoDrive na Internet.  


## Usar reboques com sem-fim

  
Os reboques com sem-fim são muito simples de usar.  
Tal como com os reboques, usas o ícone de alvo para escolher o campo onde queres descarregar uma ceifeira.  
Para iniciar o descarregador, coloca-o novamente no campo ou a menos de 20 metros do campo.  
Se o reboque com sem-fim estiver cheio, procura automaticamente um reboque no campo ou perto dele para transferir a carga.  
Caso o reboque esteja cheio e o reboque com sem-fim ainda não esteja vazio, procura outro reboque para descarregar.  
Se não houver reboque disponível, continua a descarregar a ceifeira.  


## Descarregar no campo

  
A posição de descarga pode ser selecionada com o marcador de descarga.  
A posição precisa de estar no mesmo campo ou perto do limite do campo.  
Se o marcador apontar para um monte já existente,  
esse monte é usado para descarregar.  
A direcção do marcador é usada para a direcção de descarga.  
Adicionalmente, para reboques, é preciso selecionar o lado de despejo.
