# Kursgenerator: öar

Courseplay genererar vändtegar runt öar när ö-förbikoppling är aktiverat, så när banan först möter en ö kommer den att göra minst en hel cirkel runt den. Du kan ställa in antalet vändtegar (och därmed antalet cirklar) runt ön om du behöver mer utrymme för fordon som ska vända vid ön. Tänk på att generatorn kan bestämma sig för att generera färre vändtegar om ön ligger för nära fältgränsen

- Förbikoppling av ö: Aktiverar eller inaktiverar förbikopplingen av ön, om en ö hittas. Detta fungerar inte för anpassade fält! - Öns vändtegar: Antalet rundor runt ön kan ställas in oberoende av inställningen för vändtegen. - Öns vändtegsriktning: I vilken riktning föraren kör runt ön, t.ex. för att se till att skördetröskans rör inte ligger i frukten eller för att undvika konstiga riktningsändringar.
